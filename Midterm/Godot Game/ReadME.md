# [Game Title]: Pixel Ping-Pong Rhythm Game (ME193)

## Run (with hardware)
1. Turn on the LEGO Double Motor (paddle).
2. In `Midterm/rhythm/`, run:
   `..\..\my_env\Scripts\python.exe bridge.py`
   Hold the paddle still, BLACK side toward the screen, until it prints `[motor] roll zeroed`.
3. Start `builds/PingpongGame.exe`. Top-right should show `PADDLE OK  CAM OK`.
4. First time on a new computer: press K on the title screen and calibrate (16 swings, then Enter).

## Controls
- Paddle: wrist position moves the paddle, swing to hit, twist to flip faces.
- Song select: show an AprilTag (tag16h5) or use the arrow keys; swing or Enter to start.
- Keyboard fallback: arrows = move, Space = swing, F = flip face, Q/E = tilt, Esc = back.
